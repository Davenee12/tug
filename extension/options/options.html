Browser extension

Your iPhone, in the browser

Codes, texts and music from the tug app on this PC, right where you sign in.

Connection to tug

Check that the extension can reach tug on this PC.

    What it does

    • Fill a verification code

      On a sign-in page, right-click the code box and choose Fill code from iPhone, or press Alt+Shift+C. If there's no box, the code is copied instead.

    • Search texts and notifications

      From the toolbar popup, across what tug has on this PC.

    • Control what's playing

      Play, pause and skip on your iPhone without reaching for it.

    Nothing leaves your PC

    The extension only talks to tug on this computer. It doesn't read the pages you visit; it touches a page only when you ask it to fill a code there. tug decides what the extension may do: Settings › Developer tools has a switch for each part, and texts always wait for you to click Send in tug.
